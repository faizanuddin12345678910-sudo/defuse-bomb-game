DEFUSE THE BOMB — Admin
This admin page lets you upload a site-wide success image that all players will see after defusing the bomb. It uses the GitHub API to add or update a file in your repository (branch: gh-pages by default).
Notes: You must provide a GitHub Personal Access Token with repo access (for a public repo, the public_repo scope is sufficient). The token is only used locally in your browser and is not stored by this page. After upload, the image is available at https://{your-username}.github.io/defuse-bomb-game/assets/success.jpg (may take a few seconds).
Keep your token secret. This admin UI only runs in your browser.
